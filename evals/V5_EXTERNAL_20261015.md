# SufficePatch v5: 공개 프로젝트 3개 실측 비교

**결론: v5는 세 공개 프로젝트의 실제 버그 수정에서 9/9회 성공했다. v4도 9/9회 성공했다.** 합계 기준 v5의 총토큰은 7.27%, 에이전트 작업 시간은 8.84% 감소했다. 다만 프로젝트를 균등하게 비교한 사전 정의 지표와 반복 편차를 고려하면, 일관된 토큰·시간 개선을 입증한 결과는 아니다.

평가일: 2026-10-15. 고정된 과거 upstream 버그를 로컬 체크아웃에서 수정한 결과이며, 최신 버전이나 운영 환경 검증을 뜻하지 않는다.

## 프로젝트별 결과

각 버전 3회 반복의 **중앙값**이다. 모든 실행에서 스킬이 자동 선택되고 컨텍스트 수집 도구가 실제로 성공했다.

| 프로젝트 | 성공 v4 / v5 | v4 총토큰 | v5 총토큰 | v4 시간 | v5 시간 |
|---|---:|---:|---:|---:|---:|
| python-dotenv | 3/3 · 3/3 | 151,161 | 145,102 | 63.9초 | 73.4초 |
| packaging | 3/3 · 3/3 | 226,724 | 193,253 | 93.6초 | 80.5초 |
| itsdangerous | 3/3 · 3/3 | 124,943 | 125,527 | 45.0초 | 48.1초 |

`packaging`에서는 토큰과 시간이 모두 줄었다. `python-dotenv`는 중앙값 토큰이 줄고 시간은 늘었으며, `itsdangerous`의 중앙값은 두 지표 모두 소폭 늘었다.

총토큰에는 캐시된 입력이 포함된다. 캐시 제외 입력은 입력에서 캐시된 입력을 뺀 값이며, 실제 청구 비용은 측정하지 않았다. 별도로 보고되지 않은 추론 토큰은 추정하거나 총합에 다시 더하지 않았다.

## 사전 정의한 균등 비교

동일 프로젝트·반복 번호의 v5/v4 비율을 구하고, 프로젝트별 3회 비율의 중앙값을 낸 다음 세 프로젝트의 기하평균을 계산했다. 위 표의 버전별 중앙값을 직접 나눈 값과는 다른 지표다.

| 지표 | 프로젝트 균등 짝비교 변화 | 기술적 bootstrap 95% 구간 | 사전 개선 기준 |
|---|---:|---:|---|
| 총토큰 | -5.68% | -14.76% ~ +0.02% | 미충족: 10% 이상 감소 + 구간 상한 < 0% |
| 시간 | -1.36% | -13.98% ~ +6.97% | 미충족: 5% 이상 감소 + 구간 상한 < 0% |

프로젝트가 3개뿐인 구간은 변동을 설명하는 참고치다. 폭넓은 통계적 일반화 근거로 사용하지 않는다. `itsdangerous` v4의 시간 범위는 40.62~99.02초로, 한 번의 긴 실행이 단순 합계에 영향을 줬다. 합계 시간 감소와 대표적인 실행의 속도 개선을 동일하게 해석하면 안 된다.

## 기능 검증과 비교 조건

- v4와 v5 각각 **9/9 성공**, 자동 스킬 실행 **9/9**, 보호 파일 보존 **9/9**. 실패·시간 초과·재시도 대체 없음.
- 성공 조건: 정상 완료 + 숨겨진 버그 검증 + 기존 테스트 통과 + 후보 소스의 실제 import 경로 확인 + 기존 테스트·사용자 메모·스킬 번들 보존.
- 세 원본 버전은 숨겨진 검증에서 실패했고, 공식 수정본은 모두 통과했다. 독립 검증 항목은 dotenv 65개, packaging 202개, itsdangerous 30개다.
- dotenv는 macOS BSD `printenv`가 지원하지 않는 `--version` 관련 기존 테스트 1개를 양쪽에서 동일하게 제외했다. packaging의 기존 skip 1개도 유지했다.
- `gpt-6-astra / low`, Codex CLI `0.162.1`, Python 3.12, 프로젝트별 고정 의존성. 각 과제 3회씩, 총 18회 순차 실행. 실행 순서 seed는 `20261015`다.
- 실행별 독립 초기 체크아웃, 같은 과제 프롬프트, 해당 버전의 로컬 스킬만 활성화. 호스트 스킬·플러그인·메모리·웹 검색·다른 에이전트 사용 비활성화.
- 시간은 AI 실행 프로세스의 시작부터 종료까지다. AI의 도구 사용과 자체 테스트는 포함하며 환경 준비, 하네스 작성, 사전 대조군 검증, 사후 독립 채점은 제외한다.
- 버전 ZIP, 과제, 판정 코드, 실행 계획, 초기 파일과 프롬프트를 모델 실행 전에 고정했다. 실행 후 해시·원본 사용량·모델 설정·스킬 활성화·최종 파일을 감사해 모두 일치함을 확인했다.
- 실행 명령 감사에서 외부 정답·평가 자료 조회나 추가 설치에 해당하는 후보 명령은 0건이었다.

## 해석 범위

v5의 기본 자동 선택·컨텍스트 수집·수정·검증 흐름은 이 세 프로젝트에서 정상 작동했다. 기능 때문에 v5를 사용하는 근거는 있지만, 이 결과만으로 모든 프로젝트에서 더 빠르거나 토큰을 절약한다고 광고할 수는 없다.

공개된 과거 Python 버그 3개, 동일 모델의 낮은 추론 설정, 한 macOS 환경에 한정된다. 알려진 문제의 학습 데이터 포함 가능성, 프롬프트 캐시와 서버 지연의 영향이 있다. 스킬 미사용 대조군, 다언어 실제 프로젝트, 운영 환경, 사용자 개입 시간은 평가하지 않았다. 이번 작업은 경로가 주어진 버그 수정 과제여서 v5의 변경 파일 자동 선택·JSON·요약 모드 자체의 효율을 입증하지 않는다.
