01 / Workflow

파일에서 시작해,
관련 변경까지 확인합니다.

작은 수정은 해당 파일부터, 큰 변경은 연결된 패키지부터 진행합니다. 도우미는 Python으로 만들었지만, 대상 프로젝트는 다른 언어여도 됩니다.

  1. 대상을 좁히기

    파일·폴더를 지정하고 --scope로 패키지를 선택합니다. 폴더는 먼저 후보 경로만 보여 줍니다.

  2. 맥락을 함께 모으기

    관련 소스와 참조 후보, 테스트, 프로젝트 지침과 Git 변경을 수집합니다. 빠진 정보와 한도를 표시합니다.

  3. 수정하고 검증하기

    에이전트가 실제 프로젝트 도구로 변경과 검증을 수행합니다. 여러 패키지를 수정하면 통합 검사까지 확인합니다.

언어별 지원 범위와 한계 보기
Python
AST 기반 로컬·상대 import, src 레이아웃과 정의 심볼.
JS / TS · JSX / TSX · Vue / Svelte
상대 import·export·require·문자열 dynamic import 후보. Vue/Svelte는 inline script 범위.
Go
같은 go.mod의 로컬 패키지와 같은 패키지의 소스 후보.
Rust · C / C++
Rust의 mod·crate/self/super 후보, C/C++의 따옴표 include와 가까운 include 디렉터리 후보.
Java · Kotlin · C# · Swift · Ruby · PHP
텍스트·심볼 참조와 가까운 manifest를 검색합니다. 언어별 import를 의미적으로 해석하지 않습니다.
Shell · HTML / CSS · SQL · Config · Docs
설정·문서를 포함한 텍스트 참조와 프로젝트 정보를 함께 확인합니다.

완전한 의존성 그래프는 아닙니다. alias·동적 참조·빌드 조건·생성 코드는 추가 확인이 필요합니다. 도우미는 프로젝트 코드를 실행하지 않습니다. 상세 지원 범위 ↗

04 / Get started

다음 코드 변경에
사용해 보세요.

Python 3.9 이상, ripgrep(rg), Git이 필요합니다. 저장소를 받은 뒤 SKILL.md와 scripts/를 함께 설치합니다.

v4 ZIP 받기 ↓전체 사용법 ↗

01 / TERMINAL · Codex

git clone https://github.com/rem0116kjh/suffice-patch.git
cd suffice-patch
mkdir -p "$HOME/.agents/skills/suffice-patch/scripts"
cp SKILL.md "$HOME/.agents/skills/suffice-patch/"
cp scripts/collect_context.py scripts/context_languages.py "$HOME/.agents/skills/suffice-patch/scripts/"

02 / PROMPT

$suffice-patch packages/web의 장바구니 계산을 수정해줘. 기존 응답 형식은 유지해줘.

Claude Code는 ~/.claude/skills/suffice-patch/에 같은 파일을 설치하고 /suffice-patch로 호출합니다. Codex의 관련 요청에서 자동 선택될 수도 있지만 항상 선택되는 것은 아닙니다.
